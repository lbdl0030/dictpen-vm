# 发布说明：dictpen-vm `1.3.0`

> 有道词典笔实机固件在 PC 上的模拟开发环境。**框架不含任何固件**：一台机器会变的东西
> 全部收在 `packs/<名字>/` 这个"可拆卸固件包"里，启动时用 `--pack` 选择。
> **镜像不进本包**，请按第 3 节下载（多数可以自动下）。
> 本包内**包含**固件包里的适配文件，所以镜像到位后即可开跑。
> 发布资产：`dictpen-vm-1.3.0.zip`（约 122 MiB）。

## 0. 本次更新（相对 1.2.0，2026-10-25）

- **镜像自动下载**：`bootstrap.py` 现在真的会下 —— 八台的镜像都能直接拉下来并核对 MD5，
  大文件按 Range 多线程（默认、上限 32 线）、断点续传。a7p / p5 / x3s342 用的是**已切好**的镜像。
  只有 x6pro 的系统盘和 x7 仍需手工（见第 3 节）。
- **宿主开销**：控制台画面静止时自动降频取帧（33 → 7~8 次/秒），窗口最小化时取帧与探针一起停；
  取帧节奏改为从抓帧开始计时（同样 30 ms 配置，实际从 ~22 fps 回到 ~30 fps）。
  a7p 实测：控制台可见 QEMU ~67%，最小化 ~36%，不开控制台 ~32%。
- **RV1106 默认 2 vCPU**（原 4）：空闲宿主 CPU 少约 7%，点击到首帧仍约 160 ms。
- **包体积**：p5 / x3s342 相同的 weston 载荷合并成一份，发布包少带 70 MB 原始数据。
- **快速启动**：p5 / a7p / x3s342 快照恢复实测 3.6 / 1.8 / 3.9 s（冷启动约 95 / 73 / 90 s）；
  保存快照的两处失败修掉了（起机期 SSH 超时、额外可写盘不支持 savevm）。快照不入包，可重建。
- 单测 235 项通过。

- **文档**：`疑难排查` 新增「换目标之后画面被裁」与「双击 run-vm.cmd 没反应」两条；能力盘点补三台。

## 1. 这个版本里有什么

- 框架：`scripts/`（`dpctl` 命令面、包管理、可插拔 boot backend）、`vmgui/`（显示前端与
  `vmgui/console/` 控制台）、`docs/`、`deps/`（外部依赖清单）、根目录的 `vm-console.cmd` 等一键脚本。
- 十个固件包：`packs/{a6pro, a7p, a7pro, p5, s6pro, s7pro, x3s342, x5pro, x6pro, x7}/`
  —— 各自带 `pack.toml` + `patches/`；`images/` 为空，等你下载。
- 文档入口：先看 [`README.md`](../README.md)（门面 + 60 秒上手 + 文档地图），再按角色选
  [`docs/使用手册.md`](../docs/使用手册.md)、[`docs/固件包开发教程.md`](../docs/固件包开发教程.md)、
  [`docs/插件模型.md`](../docs/插件模型.md)、[`docs/疑难排查.md`](../docs/疑难排查.md)。

各包当前能力见各自的 `README.md` / `DEVLOG.md`；总览见 `README.md` 的"已验证能力"。

## 2. 装起来

```bat
:: 1) 解压本包
:: 2) 下载镜像（第 3 节；能自动下的就一条命令）
python scripts\bootstrap.py
:: 3) 装控制台依赖
python -m pip install PySide6                    :: 控制台需要；只用 dpctl 可跳过
:: 4) 打开控制台，选一台机器
python scripts\dpctl.py packs                    :: 先看十个包的就位情况
vm-console.cmd                                   :: 图形控制台（也可 dpctl up --pack a6pro）
```

`python scripts\dpctl.py packs <名字>` 会**逐文件核对 MD5**：缺文件或拿错版本会指出来
（`[checks]` 是硬校验，对不上 `up` 会拒绝启动）。PySide6 目前要求 Python < 3.15，建议用 3.13。

## 3. 镜像下载与命名

**从哪里下**：固件镜像独立发布在 <https://github.com/lbdl0030/dictpen-rootfs/releases>，
`scripts/bootstrap.py` 可以直接下载（见本节末）。

**目录及名称**：文件名必须和 `pack.toml` 里写的一致（否则 `packs` 报"缺文件"）。
下表左边是**目标文件名**，右边是**上游资产名**：

| 包 | 放进 `packs/<包>/images/` 的文件名 | 上游资产名 | 备注 |
|---|---|---|---|
| a6pro | `a6-2-pro-ro-rootfs.img`、`a6-2-pro-ro-boot_b.img` | 同名 | 自动下载 |
| a7pro | `a7-1-pro-ro-rootfs_b.img`、`a7-1-pro-ro-boot_b.img` | 同名 | 自动下载 |
| s6pro | `S6-1-pro-ro-system_b.img`、`S6-1-pro-ro-boot_b.img` | 同名 | 自动下载 |
| s7pro | `S7-1-pro-ro-system.img`、`S7-1-pro-ro-boot.img` | `S7-1-pro-ro-system_b.img`、`S7-1-pro-ro-boot_b.img` | 自动下载，**会去掉结尾的 `_b`** |
| x5pro | `x5-1-pro-ro-rootfs_b.img`、`x5-1-pro-ro-boot_b.img` | 同名 | 自动下载 |
| a7p | `a7p-rootfs.img`、`a7p-boot.img` | 同名 | 自动下载（已切好的镜像） |
| p5 | `p5-rootfs.img`、`p5-boot.img` | 同名 | 自动下载（已切好的镜像） |
| x3s342 | `x3s342-merged.img`、`x3s342-boot_a.img`、`x3s342-uresource.img` | 同名 | 自动下载（已合并好的镜像） |
| x6pro | `system_a.img`、`boot_a.img` | `X6pro_boot_ext4.img`（= `boot_a.img`） | ⚠ boot 可下并改名；**系统盘要从 X6pro 的 OTA 提取**，见 `packs/x6pro/DEVLOG.md` |
| x7 | `x7-system_a.img` | — | ⚠ 上游只有网盘说明文件，需自行取得 |

> **`b` 与 A/B 分区**：带 `_b` 的是 A/B 双分区机型的镜像。本框架**只读挂载**其中一份，
> 所以 s7pro 那份可以直接改名后用。

**自动下载**：`deps/manifest.toml` 为每台机器写好条目（URL / 大小 / MD5），下载与改名都由它负责 ——

```bat
python scripts\bootstrap.py --check               :: 先看缺哪些（只检查，不动文件）
python scripts\bootstrap.py --only firmware-x5pro :: 只取你用的那一台（都标了 optional）
python scripts\bootstrap.py                       :: 或一次把想要的都取齐
```

多线程默认 32 线，想省带宽用 `set DICTPEN_DL_THREADS=8`；断线后重跑会从 `.part` / 分片继续。
上表保留下来是给**手工下载**或**核对**时用的。

## 4. 第一次运行

```bat
python scripts\dpctl.py up --pack <名字>          :: 默认拉起 vmgui 显示窗口
vm-console.cmd                                    :: 或者用图形控制台
python scripts\dpctl.py fast save --pack <名字>   :: 关机后保存首页快照（约 1.5–2 分钟）
python scripts\dpctl.py up --fast --pack <名字>   :: 快照启动（无音频，秒级）
python scripts\dpctl.py screenshot                :: 截图（走 HMP，不占 QMP）
python scripts\dpctl.py tap 480 240               :: 注入一次点击（vmgui 在跑时 QMP 被它占着）
python scripts\dpctl.py down                      :: 关机
```

## 5. 已知问题

1. **Windows 上脚本被转成 CRLF 会让机器起不来** —— 症状是内核 panic 循环
   `Attempted to kill init!`。仓库已加 `.gitattributes` 根治；自己改脚本别用会加 CR 的编辑器。
   详见 [`docs/疑难排查.md`](../docs/疑难排查.md) §8.6。
2. **x6pro 首次开机要等约 6 分钟**，期间停在"正在初始化配置，请等待…"属正常
   （35 个预设包在纯软件模拟下逐个解包）。别当成卡死，之后可用快照秒级恢复。
3. **注入点击前先关掉 vmgui**：QEMU 的 QMP 通道只服务一个客户端，vmgui 默认占着它，
   `dpctl tap` 会报连接被拒。用 `--display none` 重启即可。
4. **快速启动没有声音**：快照不含 usb-audio，要声音请用普通「启动」冷启动；保存快照前必须先关机。
   听不到先查 Windows 默认输出设备是否静音或音量为 0（控制台声音页有常驻提示）。
5. **s7pro 的「听力精选」点云端专辑会崩**（应用把结果集里没有的 `task_id` 交给 `std::stoll`，
   空串抛异常）。本版已知限制，**不修**；本地导入的曲目可正常播放。
